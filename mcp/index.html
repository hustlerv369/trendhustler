01Prerequisites

You need Node.js 18+ and the TrendHustler project on your machine.
📦 Get the project
Clone & setup
git clone https://github.com/YOUR_USERNAME/trendhustler cd trendhustler npm run build # fetches live data + bakes index.html
Or if you already have it
npm run refresh # re-fetch fresh data anytime

02Claude Code

Add TrendHustler as a local MCP server. Run this once in your terminal.
💻 Claude Code CLI Recommended
Add server (run once)
claude mcp add trendhustler node /ABSOLUTE/PATH/TO/trendhustler/mcp/server.mjs
Or add to your project .claude/settings.json manually
{ "mcpServers": { "trendhustler": { "command": "node", "args": ["/ABSOLUTE/PATH/TO/trendhustler/mcp/server.mjs"] } } }
Then use it in Claude Code
# In your Claude Code session: What AI topics should I post about today? Should I post about voice agents? What's the AI market mood right now?

03Antigravity

Add TrendHustler to your Antigravity workspace as a local MCP server.
🚀 Antigravity (ClaudeGravity) Works great
Add to your Antigravity MCP config
{ "mcpServers": { "trendhustler": { "command": "node", "args": ["/ABSOLUTE/PATH/TO/trendhustler/mcp/server.mjs"], "description": "TrendHustler — AI trend signals from the underground" } } }
What to replace
# Replace this with your actual path: /ABSOLUTE/PATH/TO/trendhustler/ # Windows example: C:/Users/YourName/trendhustler/ # Mac/Linux example: /Users/yourname/trendhustler/

04Keep it fresh

Run this whenever you want to refresh the trend data (takes ~12 seconds).
cd trendhustler npm run refresh # re-cops fresh data from 8 sources (HN, GitHub, arXiv, HuggingFace, Dev.to, Reddit, ProductHunt, YouTube)
